# Regression Checklist

Run before promoting any build.

- [ ] Firebase sign-in and sign-out
- [ ] My Trips loads the correct active trip
- [ ] Six cloud lodging records remain present
- [ ] Add/edit/delete/close reservation dialog
- [ ] Map destination menu, markers, and guide links
- [ ] Vault create/unlock/lock
- [ ] Document upload and preview
- [ ] Backup export, verification, and restore
- [ ] Search, favorites, timeline, and trip-at-a-glance
- [ ] Service worker installs and offline pages open
- [ ] Diagnostics version, build ID, and cache agree
- [ ] Previous stable ZIP retained for rollback
