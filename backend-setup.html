Owner setup checklist

  1. Create a Firebase project and register a Web app.
  2. Enable Authentication. For the first test, enable Email/Password; passkeys are a later server-function milestone.
  3. Create Firestore in production mode and a Cloud Storage bucket.
  4. Deploy firestore.rules and storage.rules from this repository.
  5. Copy the Firebase web configuration into assets/js/backend/firebase-config.js and set enabled: true.
  6. Deploy this branch to a private staging URL and test with non-sensitive sample reservations only.

Do not add service-account private keys to GitHub Pages or commit them to the repository. Firebase’s browser configuration is public by design; authorization comes from Authentication and Security Rules.

Security boundary

This preview can upload only ciphertext envelopes. It does not yet connect the current vault user interface to cloud sync, invite travelers, rotate vault keys, revoke devices, or provide public-computer access.

Passport scans, payment-card information, medical records, and other high-risk documents should remain outside the app until those workflows have been implemented and independently reviewed.
