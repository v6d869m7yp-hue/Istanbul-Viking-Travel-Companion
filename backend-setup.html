Owner setup checklist

  1. Firebase Web app: configured.
  2. Email/Password Authentication: enabled.
  3. Firestore Standard database: created.
  4. Publish the v6.1 firestore.rules file.
  5. Create the owner account in Authentication if not already done.
  6. Open Trip Cloud Connection and create the encrypted connectivity-test trip.
  7. Publish storage.rules in Firebase Storage Rules.
  8. Open Travel Vault → Share & sync and tap Sync now.

Do not add service-account private keys to GitHub Pages or commit them to the repository. Firebase’s browser configuration is public by design; authorization comes from Authentication and Security Rules.

Security boundary

This release uploads only a complete encrypted Vault snapshot. Encryption occurs in the browser before Firebase Storage receives the file. Firebase receives ciphertext and synchronization metadata, not the Vault password or readable key. Invitations, key rotation, device revocation, and public-computer access remain out of scope.

Keep a separately exported encrypted backup in iCloud Drive or another secure location. Cloud synchronization is not a substitute for an independent backup.
