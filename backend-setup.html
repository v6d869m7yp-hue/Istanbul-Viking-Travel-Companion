Publish the included Storage rules

storage.rules is a real text file in the project root. GitHub may display only its filename in some views; open it with a text editor to see its contents.

  1. Open Firebase Console and select istanbul-viking-venice-travel.
  2. Choose Storage. Complete the initial Storage setup if Firebase asks.
  3. Open the Rules tab.
  4. Open this project’s storage.rules file in a text editor.
  5. Copy the entire file contents into the Firebase Rules editor, replacing the existing text.
  6. Click Publish.
  7. Return here and run the harmless Storage test.
What the rules permit

Only signed-in members of the active trip can use its protected Storage paths. The readiness path accepts objects smaller than 4 KB. All other unmatched paths are denied.

Release boundary
