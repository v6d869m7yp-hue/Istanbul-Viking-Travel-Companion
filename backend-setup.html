Owner setup checklist

  1. Firebase Web app: configured.
  2. Email/Password Authentication: enabled.
  3. Firestore Standard database: created.
  4. Publish the v6.1 firestore.rules file.
  5. Create the owner account in Authentication if not already done.
  6. Open Trip Cloud Connection and create the encrypted connectivity-test trip.
  7. Cloud Storage remains postponed until encrypted attachments are implemented.

Do not add service-account private keys to GitHub Pages or commit them to the repository. Firebase’s browser configuration is public by design; authorization comes from Authentication and Security Rules.

Security boundary

This release can create a trip-centric cloud shell and a harmless ciphertext connectivity test. It still does not upload the current local vault, invite travelers, rotate keys, revoke devices, or provide public-computer access.

Passport scans, payment-card information, medical records, and other high-risk documents should remain outside the app until those workflows have been implemented and independently reviewed.

Files prepared for deployment

firebase.json, firestore.rules, storage.rules, firestore.indexes.json, the Firebase client, and a ciphertext-only sync adapter are included.
