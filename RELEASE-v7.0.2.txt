Release v7.0.3 — Stability Recovery

This release restores the last fully tested v6.9.2 application foundation under a new cache and release identifier. It removes the experimental whole-trip synchronization hooks that caused navigation and cloud-reservation regressions in v7.0.0–v7.0.1.

Preserved:
- Firebase Authentication
- My Trips
- Six cloud lodging reservations
- Maps and guide navigation
- Encrypted Travel Vault
- Vault backup and restore
- Encrypted Vault sync
- Device registry
- Sync history

No Firebase rules change is required for this recovery release.
